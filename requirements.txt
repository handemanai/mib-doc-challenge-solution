# Runtime dependencies, pinned to the versions the scoring image builds.
# Keep in step with the pip install block in the Dockerfile, which is the
# authority; this file exists so a local checkout can reproduce the same
# environment for the test suite.
#
# The pins are load-bearing rather than incidental. RapidOCR's image
# preprocessing and the recognizer's numerics are part of the measured result,
# so resolving to different versions changes OCR output and invalidates the
# reported scores. opencv-python is listed explicitly because rapidocr
# constrains it only as >=4.5.1.48 with no upper bound.
#
# Requires Python 3.11-3.13; onnxruntime 1.20.1 publishes no wheel for 3.14.
# The image is built on python:3.11-slim.
